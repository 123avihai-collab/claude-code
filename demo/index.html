איך המידע מגיע מ-Priority לדשבורד

אופציה מומלצת: דוח מתוזמן ב-Priority ← Drive ← פרסור אוטומטי ← Firestore

1

Priority שולח דוח אוטומטית

כל בוקר ב-7:00, Priority מריץ דוח (חשבוניות / תשלומים / כתב כמויות) ושומר אותו כקובץ Excel בתיקייה ברשת.

⚙️ הגדרה: Reports → Schedule Report → File output

2

Drive Desktop / OneDrive מסנכרן לענן

תיקיית הרשת בה Priority שמר את הקובץ מסונכרנת לענן האישי שלך - Google Drive או OneDrive, לבחירתך. הקובץ עולה אוטומטית - אתה לא נוגע.

📂 אופציה A - Google Drive

דרוש: Google Drive Desktop מותקן ומחובר לחשבון אישי

☁️ אופציה B - OneDrive (אישי)

דרוש: OneDrive client מותקן ומחובר לחשבון Microsoft אישי

3

Cloud Function זיהתה קובץ חדש

פונקציה ב-Firebase מאזינה ל-webhook של הענן שבחרת (Google Drive API או Microsoft Graph API). ברגע שהקובץ עולה - היא ניגשת אליו, מפרסרת את ה-Excel ומכניסה את השורות ל-Firestore.

⚙️ Cloud Function + Drive/Graph webhook · ~50 שורות קוד לכל ספק

4

הדשבורד שלך מתעדכן בזמן אמת

Firestore Listener בדפדפן/נייד שלך מקבל push ברגע שיש שורה חדשה. המסך מתעדכן - בלי refresh.

⚙️ Firestore onSnapshot · אוטומטי

📌 מה חשוב להבין: אתה לא מעלה קבצים לאפליקציה ידנית. אתה רק שומר ל-Drive (אוטומטית מ-Priority או ידנית) - והאפליקציה דואגת לשאר.
