## מה למדנו על המודל של פרויקט 2253 (תשתיות אנרגיה)

### יחסי הקבלה
```
תע"א (תעשייה אווירית) ← מזמין סופי
  ↓
י.ר.נ בנייה ופיתוח ← קבלן ראשי
  ↓
לסיכו ← קבלן משנה (אנחנו)
  ↓
ספקי משנה (קבלני עפר, ריתוכים, צביעה וכו')
```

### חוזה
- היקף: **₪14,782,679** (כולל חריגים מאושרים; חוזה מקורי ~₪13M)
- מצטבר עד היום (חשבון 8 בטיוטה): **₪11,970,832** (81%)
- 84 סעיפים ב-BoQ, מ-4 פרקים: 01.38 (מתקני דלק), 02.01 (עפר), 02.38 (צנרת דלק), 03.91 (נוספות) + 3 חריגים

### עיכבונות (קריטי!)
- **תע"א מעכבת 10%** מהמוגש (לפעמים שונה — לפעמים 0%, לפעמים 100% פר סעיף!)
- **י.ר.ן מעכבת 5% נוספים** (קבועה)
- חשבון 8: עיכבון מצטבר תע"א ₪1,197,084 + י.ר.ן ₪545,948 = **₪1,743,032 כסף "תלוי"**

### תגליות חשובות בקובץ של אביחי
1. **% התשלום פר סעיף משתנה**: 1.0 = שולם 100% / 0.9 = 10% עיכבון / 0 = הוחזק לחלוטין
2. **מתקני דלק** (לומפסם ₪1.65M) מקבל **0% עיכבון** ברוב החשבונות
3. **רג"י (02.38.07.*)** הוחזקו 100% בחשבון 6, שוחררו 100% בחשבון 7, ובחשבון 8 חלקם הוסרו לחלוטין
4. **חשבון 8 כולל 5 קיזוזים רטרואקטיביים** = ₪380,590 שצריך לדרוש מחדש:
   - V1/V3/V4/V9 valves -₪315K (הגדול)
   - רתך / מסגר / Caterpillar / JCB
