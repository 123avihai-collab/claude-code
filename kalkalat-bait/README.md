# כלכלת בית — אפליקציית ניהול תקציב משק בית

אפליקציית עמוד יחיד (Single HTML file) לניהול תקציב משק בית בעברית (RTL).
כל הלוגיקה רצה בדפדפן בלבד — שום נתון לא נשלח לשרת. ספריות קריאת ה‑Excel
(SheetJS) וקריאת ה‑PDF (pdf.js) מוטמעות בתוך הקובץ, כך שהאפליקציה עובדת גם
ללא אינטרנט.

## הקבצים
- **kalkalat-bait.html** — הגרסה הנקייה (מתחילה ללא נתונים). זו הגרסה לשימוש אמיתי.
- **kalkalat-bait-demo.html** — גרסת דמו עם נתוני דוגמה.

לשימוש: פותחים את הקובץ בדפדפן (דאבל-קליק). אין צורך בהתקנה.

## המסכים (8)
סקירה · תנועות · 🧾 תלוש שכר · תקציב · צפי (תזרים שנתי) · סיכום שנתי · חסכונות · הגדרות.

## יכולות עיקריות
- **ייבוא Excel** של דוחות אשראי (כאל / מקס) ושל דפי עו"ש בנקאיים — זיהוי עמודות
  אוטומטי, זיהוי פורמט תאריך (DD-MM מול MM-DD), ובחירת חודש שיוך ידנית.
- **חודש חיוב (אשראי):** משויך למחזור החיוב לפי תאריך החיוב; זיכוי/החזר נרשם
  כהוצאה שלילית כך ש"סך הוצאות" שווה לסה"כ הנטו שבדוח.
- **דף עו"ש:** עמודת זכות/חובה חתומה — שלילי=הוצאה, חיובי=הכנסה (כולל מינוס
  יוניקוד/סוגריים).
- **קיטלוג אוטומטי** של בתי עסק לקטגוריות + זיכרון נלמד; כפתור "סווג מחדש".
- **🧾 מנתח תלוש שכר 2026 (חילן)** — חילוץ אוטומטי מ‑PDF לפי **קוד התלוש** (מפתח יציב,
  לא לפי תוויות עברית הפוכות): הכנסות (001/151/202/266/333, כולל מילואים רטרו עם כמה
  מופעים), גילום וזקיפות (190/295/300/303/304…), פנסיה (181) וקה"ש (201). מחשב ב"ל,
  בריאות ומס לפי חוק 2026, ברוטו 1/2, וכן **מס בשתי שיטות**: חודשי (A) ו**מצטבר (B —
  שיטת חילן, הקובעת)** שפורסת את ההכנסה על השנה ומדויקת בחודשי ספייק. כולל **בדיקות
  Reconciliation** (ברוטו1/ברוטו2/נטו) שמסמנות חודש כ"דורש בדיקה ידנית" בכשל, השוואת
  מחושב מול בפועל, וצ'קליסט תקינות + התראת מדרגות 2025 לינואר–מרץ. עובר את ה‑Golden
  Test (מאי 2026) במדויק. חילוץ מ‑PDF (pdf.js) או הדבקת טקסט.
- **🔒 נעילת חודש** — כשסיימת לבדוק חודש, לחץ "🔓 נעל" ליד שם החודש. חודש נעול חסום
  מפני שינוי בטעות: ייבוא Excel, חילוץ תלוש, עריכת שדות, והוספה/מחיקה/העברה של תנועות
  כולם נחסמים (ייבוא רב-חודשי ידלג על החודש הנעול בלבד). פתיחה ידנית בלחיצה חוזרת
  (עם אישור). מצב הנעילה נשמר ונכלל בגיבוי/שחזור.
- **תקציב ברמת תת-קטגוריה** עם אקורדיון; תקציב הראשית = סכום התת-קטגוריות.
  פס ירוק עד עמידה מדויקת, אדום רק בחריגה. שורת סה"כ חודשית (תקציב/נוצל/יתרה).
- **תזרים שנתי רב-שנתי (צפי)** — טבלת 12 חודשים (הכנסה/הוצאה/מאזן/הועבר לחיסכון/
  חיסכון מצטבר/סטטוס), בפועל גובר על תכנון, דריסה ידנית לחודשים עתידיים, מעבר
  בין שנים, ודגלי גירעון.
- **מצב חשבונות** בסקירה (עו"ש / חיסכון / פנוי) — מסונכרן עם מסך חסכונות.
- **תנועות:** סיכום אקורדיון לפי מקור, חיפוש חופשי, הערת משתמש לכל שורה, מחיקה עם
  שחזור (Undo). **מחיקה מרובה** — תיבת סימון לכל שורה, "בחר הכל"/"נקה", "מחק נבחרים"
  ו"מחק הכל" (לפי הסינון הפעיל), עם אישור ושחזור; שורות בחודש נעול מדולגות.
- **ייבוא ללא כפילויות** — בייבוא אשראי/עו"ש המערכת משווה תאריך+סכום+תיאור+מקור מול
  הקיים, מדלגת על כפילויות ומדווחת כמה נוספו וכמה דולגו.
- **מנתח התלוש כאקורדיון** — כל החודשים ברשימה אנכית; כל שורה מציגה נטו, ולחיצה
  פותחת את הפירוט המלא (חישוב מול בפועל + צ'קליסט) לאותו חודש בנפרד.
- צבע פסטל ייחודי לכל קטגוריה (באדג'), גרירת פריטי התפריט לשינוי סדר.
- תצוגת אגורות (2 ספרות), שמירה אוטומטית ב‑localStorage + גיבוי/שחזור JSON.
- **בטיחות נתונים** — 5 נקודות שחזור מתגלגלות בדפדפן (כל ~30 דק'), תזכורת גיבוי
  בכניסה אם עברו 3 ימים, ואפשרות **גיבוי אוטומטי לקובץ** (הורדה אוטומטית בכניסה).
- **☁️ סנכרון בענן (אופציונלי, Firebase)** — אופליין נשאר ברירת מחדל. אחרי הזנת
  apiKey+projectId והתחברות באימייל+סיסמה, כל ה‑state מסונכרן ל‑Firestore (push/pull,
  last-write-wins עם זיהוי קונפליקט), עם **שיתוף משק‑בית** לבן/בת הזוג דרך קוד שיתוף.

## הקמת סנכרון ענן (Firebase) — חד-פעמי
1. ב‑[console.firebase.google.com](https://console.firebase.google.com) → **Add project**.
2. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable**.
3. **Build → Firestore Database → Create database** (Production mode). בלשונית **Rules**
   הדבק והפעל:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /households/{hid} {
      allow get, write: if request.auth != null;   // קוד-שיתוף אקראי ולא-ניתן-לניחוש
    }
    match /userHouseholds/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
4. **⚙️ Project settings → General → Your apps → Web (</>)** → רשום אפליקציה → העתק
   מתוך `firebaseConfig` את **apiKey** ואת **projectId**.
5. באפליקציה: **הגדרות → ☁️ סנכרון בענן** → הדבק apiKey+projectId → התחבר באימייל+סיסמה
   (פעם ראשונה יוצרת משתמש). לשיתוף: שלח לבן/בת הזוג את "קוד השיתוף", והם מזינים אותו אצלם.

> הערה: החוקים מתירים גישה למסמך משק-בית לכל משתמש מחובר שמכיר את מזהה משק-הבית
> (UUID אקראי = קוד השיתוף). זה מודל "סוד-בלתי-ניתן-לניחוש". אפשר להחמיר בהמשך לרשימת
> חברים מפורשת.

## טכני
- **רספונסיבי לנייד/טאבלט/מחשב** — אותו קובץ: במחשב תפריט צד, בנייד תפריט תחתון
  (tab-bar), טבלאות נגללות אופקית, יעדי-מגע גדולים, ובלי זום אוטומטי ב-iOS.
- קובץ יחיד (~2.5MB, כולל SheetJS + pdf.js מוטמעים). אופליין-first.
- מיגרציות אוטומטיות: מבנה קטגוריות (catStructV), המרת זיכויים, אתחול מצב חשבונות.
