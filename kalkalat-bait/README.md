# כלכלת בית — אפליקציית ניהול תקציב משק בית

אפליקציית עמוד יחיד (Single HTML file) לניהול תקציב משק בית בעברית (RTL).
כל הלוגיקה רצה בדפדפן בלבד — שום נתון לא נשלח לשרת. ספריית קריאת ה‑Excel
(SheetJS) מוטמעת בתוך הקובץ, כך שהאפליקציה עובדת גם ללא אינטרנט.

## הקבצים
- **kalkalat-bait.html** — הגרסה הנקייה (מתחילה ללא נתונים). זו הגרסה לשימוש אמיתי.
- **kalkalat-bait-demo.html** — גרסת דמו עם נתוני דוגמה.

לשימוש: פותחים את הקובץ בדפדפן (דאבל-קליק). אין צורך בהתקנה.

## יכולות עיקריות
- **ייבוא Excel** של דוחות אשראי (ויזה כאל / ויזה מקס) ושל דפי עו"ש בנקאיים — זיהוי
  עמודות אוטומטי, ללא מיפוי ידני.
- **קיטלוג אוטומטי** של בתי עסק לקטגוריות, עם זיכרון נלמד (בית עסק → קטגוריה).
- מסכים: סקירה, תנועות, הכנסות, תקציב, דוחות, צפי/תכנון, חסכונות, הגדרות.
- **תקציב ברמת תת-קטגוריה** עם תצוגת אקורדיון; תקציב הקטגוריה הראשית = סכום
  תת-הקטגוריות (חישוב אוטומטי).
- צבע פסטל ייחודי לכל קטגוריה (באדג'), סינון לפי קטגוריה/מקור, מיון לפי שם,
  סיכומים דינמיים, מחיקה עם שחזור (Undo).
- שמירה אוטומטית ב‑localStorage + גיבוי/שחזור לקובץ JSON.

## כללי לוגיקה חשובים
- **חודש חיוב (אשראי):** כל דוח אשראי משויך למחזור חיוב אחד לפי תאריך החיוב
  (חתך ה‑10 לחודש). תופס נכון גם תשלומים וגם חיובי חו"ל מיידיים.
- **זיכוי/החזר באשראי:** נרשם כ**הוצאה שלילית** באותה קטגוריה (לא כהכנסה), כך
  ש"סך ההוצאות" שווה לסה"כ הנטו שבדוח. הכנסות נשארות 0 עד עדכון ידני.
- **דף עו"ש:** עמודת "זכות/חובה" חתומה — שלילי=הוצאה, חיובי=הכנסה. זיהוי אוטומטי
  של פורמט התאריך (D/M/Y וגם M/D/Y אמריקאי). חודש לפי תאריך התנועה.
- **תצוגת סכומים:** שתי ספרות אחרי הנקודה (אגורות) בכל האפליקציה.
- **מיגרציות:** מבנה הקטגוריות וההמרות (זיכויים) מוחלים אוטומטית גם על נתונים
  שמורים קיימים, תוך שמירת התנועות.

## מבנה הקטגוריות הנוכחי (הוצאות)
דיור · ביטוחים · מנויים · אוכל · בריאות · ילדים · אורח חיים · בנייה רקפות —
כל אחת עם תת-קטגוריות ויעד חודשי כתקציב.

## הערה — קיטלוג אוטומטי
כללי הזיהוי האוטומטי (RULES / MAX_CAT_MAP) עדיין ממפים לשמות הקטגוריות הישנים.
שלב המשך מומלץ: עדכון המיפוי לקטגוריות החדשות + כפתור "סווג מחדש".
